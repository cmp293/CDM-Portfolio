My Digital Media Narrative

This project described my past experiences with technologies and coding. It demonstrates how technology has influenced my life and how it affects the work I do now.

Webtext Experiment

This project was my experiment with using text coding to create simple animations. I wanted to combine my interest in art and animation with coding.

Multi-Page Webtext Experiment

I made this project to combine my love of storytelling with coding. I was able to experiment with creating a multi-paged project in the form of a "choose your own adventure" story.

Course Goals


1. Consider technology’s role in acts of making

I learned a lot about technology and its uses within these projects. Technology is a tool that can be used to make so many different things. I experimented with it to make small animation pieces and stories in a different format than I would've without technology. Technology can help and elevate making in a unique way from other mediums. Learning to use technology can help an artist enhance their work.

2. Embrace experimentation

I didn't have much experience with coding so every project was an experiment for me. I had to constantly try new things and use trial and error to create my projects. I was able to embrace experimentation because the class has an environment that allows for mistakes and leaves room to fix things later. I felt like I could try more complicated concepts because I wouldn't be penalized for failing at them. It was very useful for experimenting and learning new skills.

3.Engage with others in a workshop environment

Because I wasn't very familiar with code, the workshop environment was very important. The various projects allowed me to interact with my classmates and learn from them how I could improve my projects and fix problems I was having. I used what I learned from other students in my future projects to make them better. Most of what I have learned about coding, I learned from engaging with others doing workshop sessions in class.

4. Practice revision within and across media forms

Revision was a big part of my process because often, my projects did not fully work the first time. I learned quickly how difficult it was to make my work in Visual Studio Code compatible with GitHub on the first try. Small tweaks could break the whole system. I needed to learn what mistakes I needed to look for and how to revise problems I ran into. Different problems required different solutions and I had to use trial and error to figure out how to make everything work.

5. Learn to present your work

I became much more comfortable presenting my work to the class while presenting my experiments. I felt comfortable because the class created a welcoming environment that allowed for sharing and accepted mistakes. I wasn't afraid I was going to be judged for what I made. I was able to experiment with coding and technology and show my findings to the class because I knew everyone was learning together. I enjoyed being able to share my projects with others.
